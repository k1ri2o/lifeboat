# Lifeboat v0.1.2 (beta)

## New look
The whole app was redesigned so anyone can use it without knowing anything about backups:
- **Home** answers one question in big letters: are my files safe? Green when all is well, amber with one button when something needs you, red with a "Restore files from before …" button if ransomware is suspected.
- **First start** walks you through 3 steps: pick the backup drive, pick folders, set a password and print the recovery key.
- **Restore** shows a plain list of dates. Files always come back into a new folder, so nothing is overwritten.
- **Plain words everywhere.** Errors say what to do; the technical text is behind a small "Details" link.
- Light and dark mode follow Windows.

## Upgrading
Run the new installer over the old one. It stops the service, updates it and starts it again. Your folders and backups are kept.

This is a beta, and the installer is unsigned, so Windows SmartScreen asks you to confirm ("More info" → "Run anyway"). Check the download against `SHA256SUMS.txt`:

```powershell
Get-FileHash .\Lifeboat_0.1.2_x64-setup.exe -Algorithm SHA256
```
