## Lifeboat 0.1.4

- Setup no longer asks you to type a drive letter. After you pick a drive, Lifeboat shows the letters on that drive (for example D:) and picks one for you.
- Drives inside the computer are now labelled "The drive Windows runs on" or "A second drive in this computer", with their letters.
- A second drive is now shown as a good choice. The warning only appears for the drive Windows runs on.
- Install over the old version. If Windows warns you, click More info, then Run anyway.
