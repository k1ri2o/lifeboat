## Lifeboat 0.1.5

**Fixes setup on a second internal drive.** In 0.1.4 the wizard offered a second drive in the computer (for example a D: drive), but setup then stopped with "disk 1 is not the system disk; use external setup". Setup now makes room on that drive the same way it does on the Windows drive.

**Your other drives stay visible.** Lifeboat takes a backup drive offline between backups only when nothing else lives on it. A drive that also holds D: (or any other drive) always stays online, so D: never disappears.

Install over the old version. If Windows SmartScreen appears, click **More info → Run anyway**.
