## Lifeboat 0.1.7

**Fixes "not found: new Lifeboat volume" right after setup made the partition.** Windows takes a hidden partition's address away, so Lifeboat could not find the partition it had just made. Lifeboat now unhides the partition only while it is backing up, restoring or setting up, waits for Windows to mount it, and hides it again as soon as it is done. At rest the partition stays hidden, with no drive letter.

**Setup reuses a partition an earlier attempt already made.** If you retry setup, Lifeboat picks up the hidden partition that is already there instead of making a second one.

**Stronger lock on the backup partition.** Only Windows itself (SYSTEM) and the Lifeboat service can open it. Even an administrator account cannot list its files.

Install over the old version, then run setup again. If Windows SmartScreen appears, click **More info → Run anyway**.
