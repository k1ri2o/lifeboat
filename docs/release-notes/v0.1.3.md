# Lifeboat v0.1.3

## Fixed
- Setting aside more space than your drive can spare no longer shows a confusing "bad command output" error. Lifeboat now says plainly that the drive does not have room, tells you the most it can set aside there, and suggests entering a smaller number, freeing up space, or using a USB drive instead.
- Step 1 of setup now explains that the size must fit in the drive's free space.

## Install
Download `Lifeboat_0.1.3_x64-setup.exe` below and run it over your old version. If Windows SmartScreen warns you, click "More info", then "Run anyway". Check the file against `SHA256SUMS.txt` if you want to be sure it is the real one.
