## Lifeboat 0.1.6

**Fixes "Not enough available capacity" during setup.** On some drives the space Windows frees is a little less than the size you picked (up to 1 MB), because Windows lines partitions up on 1 MB steps. Setup now makes the Lifeboat partition fit the space that is really there instead of failing.

**A failed setup can be retried.** If an earlier setup already made room on the drive, setup reuses that space and does not shrink the drive a second time.

Install over the old version. If Windows SmartScreen appears, click **More info → Run anyway**.
