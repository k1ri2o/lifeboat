## Lifeboat 0.1.8

**Restore works again.** Restore could not reach the hidden partition, so it failed. Lifeboat now unhides the partition for the restore and hides it again right after.

**See what's backed up.** The home screen shows when the last backup ran and how many versions are saved. "See what's backed up" opens the newest version so you can browse its folders and files.

**Pick what to restore.** Choose a version, tick the files or folders you want, and Lifeboat puts them in a new folder on your Desktop (or one you choose). "Open folder" takes you straight there.

**Vault.** Move files into the safe so they are kept only there, not on your PC. Lifeboat checks every file arrived in the safe before it removes the originals. Vault files are never cleaned up by the backup schedule. Take them out again any time with your password.

**Restart as administrator.** When a step needs administrator rights, one button restarts Lifeboat as administrator (Windows asks you to confirm).

**Only one Lifeboat window.** Opening Lifeboat again brings the open window to the front instead of starting a second copy.

**Clearer screens.** Tidier layout, bigger buttons, loading indicators and plain-language errors.

Install over the old version. If Windows SmartScreen appears, click **More info → Run anyway**.
