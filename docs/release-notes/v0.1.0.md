First public build of Lifeboat: pick folders, and it keeps encrypted, versioned backups of them on a hidden partition that ransomware can't easily reach. See the [README](https://github.com/k1ri2o/lifeboat#readme) and [the plan](https://github.com/k1ri2o/lifeboat/blob/main/docs/PLAN.md).

## This is a beta

- The automated tests pass, but the full test run in a Windows VM (simulated ransomware, mass delete, full disk, forgotten password) is not done yet. Try it on a spare PC or VM before you rely on it, and keep your other backups.
- The installer is **not code-signed** yet. Windows SmartScreen will warn: click **More info → Run anyway** only if the checksum below matches.

## Install

1. Download `Lifeboat_0.1.0_x64-setup.exe` and `SHA256SUMS.txt`.
2. Check the file in PowerShell: `Get-FileHash .\Lifeboat_0.1.0_x64-setup.exe` must match the line in `SHA256SUMS.txt`.
3. Run the installer. It needs admin rights, because it installs the `lifeboat-svc` background service that does the backups.

## Before you start

- Write down your backup password and **print the recovery key** shown at setup. Without one of them nobody can restore the backups, not even us.
- Uninstalling removes the app and the service but **keeps the backups** on the hidden partition.
