# Lifeboat v0.1.1 (beta)

## Fixed
- **"Add a folder" failed on a fresh install** with "The specified path could not be found (os error 3)". The service's data folder (`C:\ProgramData\Lifeboat`) was only created on the first settings save, but adding a folder writes another file there first. The service now creates the folder (locked to the service) when it starts.

## Upgrading
Run the new installer over the old one. It stops the service, updates it and starts it again. Your folders and backups are kept.

Everything else in the [v0.1.0 notes](https://github.com/k1ri2o/lifeboat/releases/tag/v0.1.0) still applies: this is a beta, and the installer is unsigned, so Windows SmartScreen asks you to confirm ("More info" → "Run anyway"). Check the download against `SHA256SUMS.txt`:

```powershell
Get-FileHash .\Lifeboat_0.1.1_x64-setup.exe -Algorithm SHA256
```
