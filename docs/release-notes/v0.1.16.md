## Lifeboat 0.1.16

**Make Lifeboat bigger.** Settings → Backup drive shows how full Lifeboat is. If the drive has free space right after the Lifeboat partition, **Make bigger** grows it (your password is needed). It can only grow, never shrink, and your backups are not touched.

**Delete Lifeboat.** Settings → Danger zone → **Delete Lifeboat** removes the hidden partition with all backups and vault items. It needs your password (or recovery key) and the word DELETE typed in a box. On an internal drive the freed space goes back to the drive next to it.

**Back button in setup.** Setup steps now have a Back button, so you can change your mind on "Where should your backups go?".

**Drive details.** Settings has a "Your drives" card that shows every drive with its size, type (internal, USB, ...) and a "Lifeboat is here" tag on the drive that holds Lifeboat, plus how full the backup space is, how many backups and vault files there are, and the last health check.

Since 0.1.5 (the last release on GitHub) Lifeboat also got: working restore and a file browser, the vault (keep files safe, remove items with a 7-day delay), Delete backup with a 7-day delay, the partition stays hidden except while in use, a faster and redesigned app, and many setup fixes.

Install over the old version. If Windows SmartScreen appears, click **More info → Run anyway**.
