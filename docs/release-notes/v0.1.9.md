## Lifeboat 0.1.9

**Much faster.** Opening versions, folders and the vault no longer waits several seconds per click. Lifeboat opens the hidden partition once, keeps it open while you browse, and hides it again 30 seconds after you stop. File lists of a version are loaded once and kept in memory, so moving between folders is instant.

**New look.** A side menu (Home, Restore, Vault, Settings), a big status card on Home with the last and next backup, larger text and dark mode that follows Windows.

**Fewer glitches.** No more flicker on refresh, buttons can't fire twice, slow answers from a screen you already left no longer show up, spinners always stop, and grey placeholders show while things load.

Install over the old version. If Windows SmartScreen appears, click **More info → Run anyway**.
